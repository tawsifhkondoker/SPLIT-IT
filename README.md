# SPLIT-IT
SPLIT IT is a simple bill splitting tool designed to make group payments quick and stress free. Enter your bill, add tax and tip, choose the number of people, and SPLIT IT instantly shows how much everyone should pay . Just a simple way to split the bill.

# Development
Clone the source code to your device
 git clone https://github.com/tawsifhkondoker/SPLIT-IT.git && cd escopo
Open the project in your code editor.
Start the app by opening index.html in your browser.

# Notes
The app is built using plain HTML, CSS, and JavaScript.
